## 📌 Sobre o Repositório

Este repositório reúne alguns dos códigos desenvolvidos durante minha estadia no grupo de robótica competitiva UTBots (04/2025 ~ 11/2025), abrangendo soluções essenciais de navegação e tomada de decisão como árvores de comportamento, geometria computacional para visibilidade do gol e simulação de trajetórias via raycasting com reflexões.

---

## 🧠 Conceitos e Tecnologias Aplicadas

* **Linguagem:** Python 3
* **Arquitetura de Decisão:** Behavior Trees (`py_trees`)
* **Geometria Computacional:** Tangentes entre reta e circunferência, raycasting, equações paramétricas e detecção de intersecção em 2D.
* **Algoritmos:** Busca recursiva de menor caminho, ordenação e filtragem de vetores angulares.
